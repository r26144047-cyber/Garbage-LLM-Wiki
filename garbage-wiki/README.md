# 台灣垃圾分類 LLM Wiki

依 Karpathy 的 LLM Wiki 模式建立，採「先討論、後生成」。

- `AGENTS.md`：給 LLM 代理人的操作說明（Ingest、Query、Lint 的步驟與禁止事項）
- `SCHEMA.md`：內容寫作規則
- `index.md`：目錄
- `log.md`：更新紀錄
- `raw/`：原始資料（S1–S5，只讀）
- `wiki/`：categories、items、concepts、law、sources、maintenance
- `scripts/`：`lint.py`（結構檢查）、`build.py` + `template.html`（產生網站 HTML）
