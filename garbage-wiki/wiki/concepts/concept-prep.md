# 回收前處理

S2 各材質的交付注意事項，可以歸納成幾個共通動作。（本頁為跨頁整理）

| 動作 | 適用 | 依據 |
|---|---|---|
| 倒空殘餘物 | 所有容器 | 〔S2〕 |
| 略為沖洗或擦拭 | 鐵鋁玻璃塑膠容器、紙餐盒 | 〔S2〕 |
| 壓扁 | 鐵鋁容器、塑膠容器、鋁箔包 | 〔S2〕 |
| 拆開不同材質 | 紙類去膠帶與釘書針、鐵鋁用品去附著物、保麗龍去膠帶與鐵釘、光碟去外殼 | 〔S2〕 |
| 分開打包 | 一般紙類與紙容器、鋁箔包分開 | 〔S2〕 |
| 剩菜先倒廚餘 | 紙或塑膠餐盒 | 〔S2〕 |
| 危險物單獨處理 | 高壓罐、鋰電池、燈管 | 〔S2〕 |
| 尖銳醫療物裝硬瓶並標示 | 居家針頭（[[item-needle]]） | 〔S5〕◇ 非官方（媒體報導） |

## 中央法規的排出原則〔S1〕
執行機關應宣導民眾：廚餘先瀝乾水分並包好；刀片、玻璃碎片等尖銳物用不易穿透的容器或材質包好並標示；木、竹片裁剪後綑紮；封緊垃圾袋口；有害垃圾分開貯存排出。

## 為什麼要做
「看起來像可回收」不等於能回收。污染或複合材質會降低再利用比例、影響再生品質（見 [[item-receipt]]）。
