# 垃圾分類的法定定義：五類與三類

## 法定五類〔S1〕

| 類別 | 一句話判斷 | 交付管道 |
|---|---|---|
| [[cat-bulky]] | 體積大的傢俱、樹枝 | 先預約 |
| [[cat-hazardous]] | 經公告的有害一般廢棄物 | 法定為專用車；家戶常見危險物品實務上走回收或逆向回收 |
| [[cat-food]] | 生熟食物與殘渣 | 廚餘桶 |
| [[cat-recyclable]] | 公告回收項目、應回收物品與容器 | 回收車、回收桶、交回賣家 |
| [[cat-general]] | 以上皆非 | 垃圾車 |

法規定義「分類」為：在排出、貯存、回收、清除及處理過程中，為利後續運輸與處理，把不同類別性質者分開的行為。〔S1〕

## 日常說的「強制分類三類」
學校與宣導文件常說垃圾強制分類為「一般垃圾、資源垃圾、廚餘」三大類（參見 raw/S1 參照資料）◇ 非官方（學校文件）。

這是**日常排出時的簡化說法**：家戶每天面對的主要是垃圾車、回收車、廚餘桶三個出口。巨大垃圾與有害垃圾頻率低，又需另外預約或交專用車，因此常被省略。

## 對照

| 法定五類 | 日常三類 |
|---|---|
| 資源垃圾 | 資源垃圾 |
| 廚餘 | 廚餘 |
| 一般垃圾 | 一般垃圾 |
| 巨大垃圾 | 另行預約，不在三類內 |
| 有害垃圾 | 交專用車，不在三類內 |

## 判斷順序建議
因為一般垃圾是剩餘類別，判斷時可依序問：太大嗎？有害嗎？是食物嗎？可回收嗎？都不是，才丟垃圾車。（本 wiki 依 S1 定義整理的判斷流程）

注意「有害嗎？」這一步：電池、燈管、高壓罐等走資源回收〔S2〕，針頭、藥品走醫院或藥局〔S5〕◇ 非官方（媒體報導），並不是都交專用車。請看 [[cat-hazardous]] 的管道對照表。
