# 代理人操作說明（AGENTS.md）

你是這個「台灣垃圾分類 Wiki」的維護者。本檔說明你**怎麼做事**；內容寫作規則見 SCHEMA.md。兩者衝突時，以使用者當下的指示優先，其次 SCHEMA.md，再其次本檔。

本 wiki 在 **claude.ai 網頁對話**中維護。網頁對話不會自動讀取本檔，每次對話的工作資料夾也會清空，所以請嚴格照「開工」與「收工」流程執行。

## 開工流程
1. **以使用者上傳的 zip 為準**，解壓縮到工作資料夾。
2. 若這次沒有上傳 zip：先問使用者要上傳 zip，或改從網站讀回（Artifact 的 read 動作）。不可假設手上已有最新版。
3. 依序讀取：本檔、`SCHEMA.md`、`index.md`、`log.md` 最後 3 筆、`wiki/maintenance/` 中最新的健康檢查報告。
4. 先向使用者回報：目前有幾篇來源、幾頁內容、未解決的待釐清與時效提醒。

## 收工流程（這次有任何修改就要做）
1. 執行 `python3 scripts/lint.py`：斷鏈與孤兒頁必須為 0。
2. 執行 `python3 scripts/build.py` 重建網站，並以同一個網址重新發布：https://claude.ai/artifact/Nn72wkrBCABFUswgrkwVbu
3. 打包新的 `garbage-wiki.zip` 交給使用者。要用會標記 UTF-8 檔名的方式打包，例如 Python 的 zipfile。
4. 在 `log.md` 追加一筆，格式為「## [YYYY-MM-DD] 類型 | 標題」。

## 修改的兩個等級

| 等級 | 包含哪些修改 | 怎麼處理 |
|---|---|---|
| 可直接做 | 錯字；斷鏈與連結修正；lint 找到的內容矛盾；有官方依據時把 ⚠ 改成 ✔ | 先做，事後在回覆中列出改了什麼，並記進 log |
| 需要同意 | 新增來源；時效到期後更新政策頁；把查詢結果存回 wiki；刪除任何內容；修改 SCHEMA.md 或本檔；新增或移除 ◇ 標記以外的來源 | 先報告，等使用者同意才寫入 |

例外：「內容矛盾」的兩邊若都是官方來源，屬於來源衝突，不算可直接修正的錯誤。此時依 SCHEMA 並列兩種說法，並提出討論。

## 來源政策
- **新來源只收政府機關的原始文件**：中央部會、立法院、行政院公報、縣市政府與環保局、全國法規資料庫、環境部主管法規系統。
- 不可作為新來源：媒體報導、民間法規網站、學校文件、公會或協會網站、個人部落格。這類資料只能幫你**找到**官方原文。
- 既有的非官方內容：保留，並在句末或表格依據欄加「◇ 非官方（類型）」。找到官方原文後替換內容並移除標記（屬可直接做），在 log 記錄。

## 操作一：Ingest（新增一篇來源，需要同意）
**第一次回覆（不寫任何檔案）**
1. 搜尋候選來源，確認是政府機關的原始文件。
2. 報告：來源是什麼、重點、預計新增與修改的頁面、與既有內容的衝突或新舊差異、需要使用者決定的問題。
3. 等待同意。

**第二次回覆（同意後）**
1. 在 `raw/` 新增整理筆記：出處、網址、取得日期、重點。檔名格式「S編號-英文簡稱.md」，只用英數。非法規文件只寫整理筆記，不轉載全文。
2. 新增 `wiki/sources/S編號.md`，新增或更新受影響的頁面，每個事實附來源編號。
3. 更新 `index.md`，執行收工流程。

## 操作二：Query（回答問題、做簡報）
1. 先讀 `index.md`，再讀相關頁面；**只用 wiki 內容回答**，不從記憶補事實。
2. 保留來源編號；⚠ 的內容說明「目前未確定」；◇ 的內容說明「來自非官方來源」；有時效的內容寫出生效日。
3. wiki 缺資料時不自行補寫，改為建議 ingest 新來源。
4. 有長期價值的回答，經同意後存回 `wiki/concepts/`。
5. 做簡報時，每張投影片都要過 1 到 3 項的檢查，不通過的投影片重新生成。

## 操作三：Lint（健康檢查）
1. 執行 `python3 scripts/lint.py`：斷鏈、孤兒頁、未列入 index、無引用頁面、frontmatter 未宣告的來源、⚠ 數量、◇ 數量。
2. 逐頁做內容檢查：互相矛盾、過期的時效內容、「將由第 N 篇補充」這類過期字樣、違反來源政策的內容。
3. 結果寫入 `wiki/maintenance/lint-YYYY-MM-DD.md`，並執行收工流程。
4. 時機：每批 ingest 完成後；時效提醒到期時。

## 禁止事項
- 不修改或刪除 `raw/` 的檔案；raw 有錯時，在對應的 `wiki/sources/` 頁面註明更正。
- 不自行刪除 ⚠；有官方依據時改為 ✔ 並寫明依據。
- 來源衝突時不自行取捨，兩種說法並列。
- 不用中文檔名；頁面連結用雙中括號包住頁面代號，代號只用英數和連字號。
